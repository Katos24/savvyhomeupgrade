# Lead2Project

Job management platform built for service contractors. Captures leads, tracks jobs from inquiry to payment, and automates follow up.

## Built With
Next.js, React, PostgreSQL, Tailwind CSS, Vercel

## Features
- Custom branded lead capture forms with photo upload
- Visual job pipeline dashboard
- Quote builder and one-click email sending
- Payment reminders and tracking
- Scheduling tools
- AI-generated project briefs and quotes
- 6AM daily digest email
- CSV export and team access
